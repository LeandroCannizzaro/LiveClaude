Release Notes

Published releases of LiveClaude.

v2.2.6

Lower macOS Info.plist minimum version to 11.0
  • macOS bundle manifest: lowered LSMinimumSystemVersion in packaging/macos/build-macos-packages.sh from 12.0 to 11.0.

v2.2.5

About dialog top banner artwork
  • About banner: added a custom widescreen header banner (about-banner.png) at the top of the About LiveClaude dialog.

v2.2.4

Live download progress bar & update status indicator
  • Update progress UI: wired IProgress<double> into ShellViewModel and added a live progress bar + status text in the top header showing download percentage, SHA-256 verification, and installer handoff before closing.

v2.2.3

Persist theme selection on Save settings
  • Theme persistence fix: updated Supervisor.SaveSettingsAsync to persist Theme (selected preset and custom color overrides) alongside general supervisor settings when saving config.json.

v2.2.2

5 new popular theme presets & sidebar User Manual
  • New Theme Presets: added Dracula, Nord, Catppuccin Mocha, Tokyo Night, and Solarized Light (10 built-in themes total, all customizable via the Color Picker).
  • User Manual & Direct Download: reorganized the product site with a sticky left sidebar, complete feature documentation, and OS/CPU-aware direct downloads (.msi, .dmg, .rpm).

v2.2.1

Cross-platform in-app auto-updater (Windows, Linux, macOS) & POSIX test fix
  • Cross-platform Auto-Update: extended update.json, InstallKindDetector, UpdateChecker, and UpdateInstaller to support in-app self-updating on Windows (MSI & ZIP), Linux (.tar.gz x64/arm64), and macOS (.dmg x64/arm64).
  • Release workflow: moved update.json generation to the release aggregation job so all OS packages and SHA-256 checksums are published together.
  • POSIX test fix: set executable permissions on temporary test CLI stubs in AgentAuthTests and AntigravityProductTests for Linux and macOS CI runners.

v2.2.0

Antigravity provider, no-scroll tabbed UI, Themes & Color Picker, MSI installer & auto-update
  • Antigravity Remote Control provider: new isolated plugin LiveClaude.Product.Antigravity supporting agy --remote-control with execution mode, reasoning effort, model, agent, project, extra directories, sandbox, and conversation resume.
  • No-scroll tabbed UI: reorganized Sessions and Service & startup with top command toolbars and inner tabs; added a dedicated Settings tab for general supervisor options, folders, products, and appearance; moved version into the top-left header and removed the footer.
  • Theme manager & Color Picker: 5 built-in presets (Default Dark, Light, Midnight Blue, Forest Dark, High Contrast) plus live per-token color customization persisted in config.json.
  • Windows MSI installer & in-app Auto-Update: per-machine WiX MSI package, portable ZIP installer, SHA-256 verified updates via update.json, and an Update button + About dialog in the top bar.
  • Documentation & install counter: expanded English user manual, release notes page, and opt-out anonymous setup counter via Hits.sh.

v2.1.3

Multi-product supervision & Cursor My Machines support
  • Multi-product architecture: isolated LiveClaude.Product.Claude and LiveClaude.Product.Cursor plugin assemblies loaded dynamically by ProductHost.
  • Cursor My Machines: support for agent worker start, multi-directory routing, and automatic Windows better-sqlite3 ABI patching.
