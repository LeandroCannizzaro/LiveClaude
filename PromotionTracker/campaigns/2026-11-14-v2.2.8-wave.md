# Wave 3 Campaign — v2.2.8 (2026-11-14)

**Release:** https://github.com/LeandroCannizzaro/LiveClaude/releases/tag/v2.2.8  
**Product page:** https://leandrocannizzaro.github.io/LiveClaude/  
**Repo:** https://github.com/LeandroCannizzaro/LiveClaude

## Key updates since v2.1.3 (Wave 1/2)

- **macOS 11 Big Sur + macOS 12+ dual packages (`v2.2.7`–`v2.2.8`):** Windows, Linux, and macOS 12+ run on `.NET 10`; macOS 11 gets a dedicated `.NET 8` build (`-macos11.dmg`), ad-hoc deep-signed (`codesign --force --deep --sign -`), HFS+ DMG, with OS-version detection in both the download page and in-app auto-updater.
- **Live update progress UI (`v2.2.4`):** Top-header progress bar + status text during download, SHA-256 verification, and installer handoff.
- **UI & persistence (`v2.2.3`, `v2.2.5`):** Custom theme persistence across restarts; About dialog top banner.
- **Linux packaging (`v2.2.1`–`v2.2.2`):** `.deb`, `.rpm`, `.tar.gz`, and one-line installer (`curl -fsSL https://leandrocannizzaro.github.io/LiveClaude/install.sh | sh`).
