**Body:**

```
Claude Code Remote Control (and Cursor My Machines) run as a foreground process in a terminal. Close the window, crash, or reboot — and your phone loses the machine.

LiveClaude turns that into a supervised service:

- one long-lived process per project/session
- OS-native restart (Scheduled Task / systemd / LaunchAgent)
- Avalonia desktop app + real embedded pty for trust/login flows
- Windows, Linux, macOS — all C# / .NET

MIT: https://github.com/LeandroCannizzaro/LiveClaude
Product page: https://leandrocannizzaro.github.io/LiveClaude/
Latest: v2.1.3

Happy to answer questions about the supervisor model or the VT emulator.

## 2. Reddit — r/ClaudeAI

**Title:** I built an open-source supervisor so Claude Code Remote Control survives reboot (LiveClaude)

**Body:**

```
**Problem:** Remote Control dies if the terminal closes, the process crashes, or the machine reboots.

**What LiveClaude does:** runs each session under an OS supervisor, with a desktop app to manage many projects and an embedded terminal for the one-time trust / login prompts. Also supports Cursor My Machines workers.

- Windows / Linux / macOS
- MIT, C# / .NET
- v2.1.3

Install:
- Windows: `winget install LeandroCannizzaro.LiveClaude`
- Linux: `curl -fsSL https://leandrocannizzaro.github.io/LiveClaude/install.sh | sh`
- macOS: `curl -fsSL https://leandrocannizzaro.github.io/LiveClaude/install-macos.sh | sh`

Repo: https://github.com/LeandroCannizzaro/LiveClaude
Site: https://leandrocannizzaro.github.io/LiveClaude/

I'm the author — feedback and bug reports welcome.
